# 📝 To-Do List API

Простой сервер для управления задачами с возможностью создания, редактирования, удаления и поиска задач.

## 🔹 Функционал

- ✅ Добавление новых задач
- ✏️ Редактирование существующих задач
- ❌ Удаление задач
- ✔️ Отметка выполнения задач
- 🔍 Поиск задач по:
  - Названию
  - Комментарию
  - Дате

## 🚀 Запуск проекта

### Требования
- Go 1.20+
- SQLite3

### Настройка
1. Создайте файл `.env` в корне проекта:
```
TODO_PORT=7540
TODO_DBFILE=todo.db
TODO_PASSWORD="123"
SECRET_KEY="gopher"
```

2. Для запуска тестов отредактируйте tests/settings.go
```
var Port = 7540
var DBFile = "scheduler.db"
var FullNextDate = true
var Search = true
var Token = `` // Вставьте сюда токен из куки после авторизации
```

Запускать тесты только после запуска сервера

## Выполненные задания со звездочкой

- ✅ Реализация аутентификации с JWT токенами
- ✅ Поддержка переменных окружения для настройки
- ✅ Middleware для защиты API endpoints

```
### Аутентификация
- `POST /api/signin` - вход в систему

### Задачи
- `GET /api/tasks` - получение списка всех задач
- `GET /api/task?id=<id>` - получение задачи по ID
- `POST /api/task` - создание новой задачи
- `PUT /api/task` - обновление задачи
- `DELETE /api/task?id=<id>` - удаление задачи
- `POST /api/task/done?id=<id>` - отметка задачи как выполненной
```
